# Suggestions and contributions

Ideas, usability reports and accessibility suggestions are welcome without code.
Explain the workflow, the difficulty and the result you want. For bugs, include
OS, Python version, app commit/version and a minimal fictional input.

Never attach a real résumé, employer/client material, contact details, private
input, evidence receipt or unreviewed export to a public issue. Use the supplied
fictional example or a newly generated fixture. See SECURITY.md for suspected
vulnerabilities.

Develop with Python 3.12/3.13 and `requirements-dev.txt`. Run the full test suite,
the source gate, and inspect rendered pages after PDF layout changes. Keep claim
labels separate from checksum results. Do not weaken schema, output, privacy or
verification checks to make a test pass. Dependency updates need pin, notice,
advisory and platform checks. Tests must use owned disposable data.

Original contributions are accepted under MIT. Retain upstream notices and
identify any proposed imported material and its terms. This project has no
paid service prerequisite or contributor agreement for leaving a suggestion.
