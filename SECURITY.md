# Security scope

This is an offline local document builder, not an evidence-authentication service.
Use explicit, stable inputs on trusted local storage and review output before
sharing. Never treat a checksum or an author-stated label as independent proof.

Use GitHub's private **Report a vulnerability** option if available. Otherwise
open a minimal issue asking for a private contact channel without exploit
details, real evidence, personal information, private files or credentials.

There is no support SLA. No advisory result or generated test suite establishes
universal security. Keep editable input separately and verify a bundle before
relying on it; incomplete output after an error is not an accepted export.
